# Sugarcane Crop Change Detection

## Overview
A multi-temporal geospatial analysis project focused on sugarcane crop identification and change detection using satellite imagery and Google Earth Engine.

## Objectives
- Analyze temporal changes in sugarcane cultivation.
- Explore vegetation indices for crop identification.
- Investigate the use of Sentinel-1 SAR and Sentinel-2 multispectral imagery.
- Develop a geospatial workflow for agricultural monitoring.

## Data Sources
- Sentinel-1 SAR
- Sentinel-2 multispectral imagery
- Google Earth Engine

## Methodology
1. Acquire and filter satellite imagery using Google Earth Engine.
2. Perform preprocessing and temporal compositing.
3. Calculate NDVI for vegetation analysis.
4. Apply NDVI-based density slicing for crop classification.
5. Analyze temporal variations in sugarcane cultivation.

## Tools and Technologies
- Google Earth Engine
- Remote Sensing
- GIS
- NDVI

## Research Context
This project was developed as part of undergraduate geospatial research involving agricultural monitoring and satellite-based crop analysis.
